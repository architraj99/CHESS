# Keyboard Chess

I made a two player chess game that you can play together on the same screen, using just a keyboard. You don't need a mouse or the Tab key to play.

White goes first, then both players take turns on the same board.

## How to play this


1. Use the arrow keys to move the highlighted square to one of your pieces.
2. Press Enter to select that piece..... Green squares show where it can move.
3. Use the arrow keys to choose a green square then  press Enter again to move or capture....
4. Pass the keyboard to the other player when the turn changes.

You can also press / and type a move like e2e4...
then press Enter. This is useful if you already know the square names.

## Keyboard controls

Arrow keys ----- Move the highlighted square around the board 

Enter ---- Select a piece or make a move 

Esc ----- Cancel the selected piece also it can close the move input 

/  Type a move using square names, like e2e4 ( /e2e4 )

U ----- Undo the last move 

F ----- Flip the board 

N ---- Start a new game 

D ----Offer a draw 

Y ----Accept a draw when one has been offered 

H ------Show or hide the keyboard help 

also If your pawn reaches the other end of the board, 
choose its new piece with Q (queen),R (rook), B (bishop), or N (knight). 
Press Enter to choose a queen.
